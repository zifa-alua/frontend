# BITLAB News — Frontend (TASK-004)

Фронтенд для новостного сервиса BITLAB. Одностраничное приложение на **чистом
HTML + CSS + JavaScript** (без фреймворков и сборки), подключается к бэкенду
из TASK-003 (Spring Boot + JWT).

Продолжение TASK-003. Бэкенд: https://github.com/zifa-alua/demo3 (ветка task3).

---

## Стек

- HTML5, CSS3, ванильный JavaScript (fetch API)
- Без Node.js, npm и сборки — файлы работают как есть

---

## Возможности

- Регистрация и вход (email + пароль)
- Лента новостей и просмотр отдельной новости
- Создание новости — только для роли **ADMIN**
- Навбар с email, ролью и кнопкой выхода
- Автоматическое обновление access-токена при 401 (refresh)

---

## Требования

- Запущенный бэкенд TASK-003 на `http://localhost:8080`
- База PostgreSQL (Docker) поднята
- В бэкенде включён CORS для origin фронтенда (`http://localhost:63342`)

---

## Запуск

1. Запустить бэкенд (проект demo3, ветка task3) и базу данных.
2. Открыть `index.html` в браузере через встроенный сервер IntelliJ
   (в редакторе навести на файл → иконка браузера в правом верхнем углу),
   адрес будет вида `http://localhost:63342/demo3-frontend/index.html`.
3. Зарегистрироваться, войти, пользоваться.

Адрес бэкенда задаётся в начале `app.js`:

```js
const API_BASE = "http://localhost:8080";
```

## Безопасность (реализовано под требования карточки)

- **accessToken хранится только в памяти** (переменная в JS), не в localStorage
  и не в sessionStorage.
- **Защита от XSS**: все данные с сервера выводятся через `textContent`,
  без `innerHTML` — вставка тегов невозможна.
- **Защищённый доступ**: без токена показывается только экран входа;
  кнопка создания новости видна только роли ADMIN.
- **Авто-refresh**: при ответе 401 фронт автоматически обновляет токен через
  `/auth/refresh` и повторяет запрос.
- **Адрес бэкенда** вынесен в одну константу (в проде — в переменную окружения).
